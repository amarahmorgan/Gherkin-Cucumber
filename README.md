## 🌟 Overview

This project demonstrates how to design and execute automated tests using **Gherkin syntax** and **Cucumber BDD framework**.

It focuses on converting human-readable requirements into automated tests that validate application behaviour.

## 🎯 Objectives

- 🧾 Write human-readable test scenarios using Gherkin  
- 🔗 Map scenarios to reusable step definitions  
- ⚙️ Automate application workflows using Cucumber  
- 🧪 Ensure traceability between requirements and tests  
- 📊 Improve regression testing efficiency
